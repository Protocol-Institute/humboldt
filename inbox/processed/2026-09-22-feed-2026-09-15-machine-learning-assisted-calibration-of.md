# Machine learning-assisted calibration of Agent-based Models: surrogate-based optimization with Genetic Algorithm and Particle Swarm Optimization

**Source:** cs.MA updates on arXiv.org
**URL:** https://arxiv.org/abs/2609.13247
**Date:** 2026-09-15
**Relevance:** Directly addresses computational methods for calibrating agent-based models using surrogate-assisted optimization techniques, which is fundamental ML methodology for expensive simulation-based inference.

## Summary

arXiv:2609.13247v1 Announce Type: new 
Abstract: Calibrating an agent-based model (ABM) is difficult because its objective landscape is stochastic and rugged, and can be evaluated only through costly black-box simulations. This study adapts inner-loop surrogate-assisted evolutionary computation (SAEC) to ABM calibration by embedding a machine-learning surrogate within genetic algorithm (GA) and particle swarm optimisation (PSO).
