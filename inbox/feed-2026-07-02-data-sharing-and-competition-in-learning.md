arXiv:2607.00168v1 Announce Type: new 
Abstract: Many modern technologies improve through use. Each unit deployed generates data that trains the next generation, so deployment is both production and an investment in a shared learning stock. We study how the architecture of this learning, whether pooled across firms or fragmented within them, interacts with firms' deployment decisions and with product-market competition.
