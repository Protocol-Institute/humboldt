# SkillApt: Learning When to Activate Agent Skills from Counterfactual Evidence

**Source:** cs.MA updates on arXiv.org
**URL:** https://arxiv.org/abs/2609.26863
**Date:** 2026-09-24
**Relevance:** Addresses the critical problem of determining when retrieved skills should actually be used by LLM agents, which is directly relevant to improving agent reliability and efficiency.

## Summary

arXiv:2609.26863v1 Announce Type: new 
Abstract: Large language model agents increasingly retrieve reusable Skills and inject them into the active context. However, a retrieved Skill can be relevant yet unnecessary, costly, or even harmful in the current execution state. We present SkillApt, a post-retrieval activation framework that decides whether a retrieved Skill should actually be loaded. SkillApt builds execution evidence from matched WITH/WITHOUT runs and uses outcomes from similar historical states to make a LOAD/ABSTAIN decision for each candidate Skill.
