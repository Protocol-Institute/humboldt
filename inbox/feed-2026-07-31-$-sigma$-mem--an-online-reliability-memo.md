# $\Sigma$-Mem: An Online Reliability Memory for LLM-based Multi-Agent Systems

**Relevance:** Directly addresses trust modeling and coordination constraints in multi-agent LLM systems, core to CL-003 and relevant to CL-002's coordination cost dynamics.

## Summary

arXiv:2607.27958v1 Announce Type: new 
Abstract: Memory is central to long-horizon LLM agents, yet existing memory systems primarily preserve interaction content rather than modeling which agents can be trusted and under what conditions. This limitation is particularly important in multi-agent systems, where a central model may be unable to directly verify plausible or correlated peer responses. We introduce $\Sigma$-Mem, an online reliability memory that records historical competence evidence for individual peers and peer relationship evidence across the peer set.
