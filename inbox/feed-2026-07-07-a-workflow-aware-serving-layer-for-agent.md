# A Workflow-Aware Serving Layer for Agentic Applications

**Source:** cs.MA updates on arXiv.org
**URL:** https://arxiv.org/abs/2607.02942

**Relevance:** Directly addresses coordination mechanisms and quality verification operators in multi-step agentic workflows, relevant to formalizing trust guarantees and operational costs in safety-critical serving systems.

## Summary

arXiv:2607.02942v1 Announce Type: cross 
Abstract: Agentic AI applications form an emerging serving workload in which a request creates a workflow: a directed acyclic graph of LLM and tool calls that exposes per-node model choices and optional quality operators such as verifiers. This workload falls between two existing layers. Model-serving engines execute individual calls efficiently but cannot see workflow structure, while agent frameworks fix the workflow but cannot see backend load, so neither jointly chooses each node's model, verifier, and backend under serving-time conditions.
