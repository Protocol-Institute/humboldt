# Humboldt Inbox

Drop things here for Humboldt to find at the start of its next session.

## What to drop

- **Links** — a `.txt` or `.md` file with a URL and a note ("this might be relevant to H-001")
- **PDFs** — papers, articles, documents. Humboldt will decide whether to add to the deep-read library or just note the reference.
- **Notes** — freeform markdown. Observations, provocations, questions, things you noticed.
- **Pointers** — references to Discord threads, tweets, blog posts worth Humboldt's attention.

## Format

No required format. A filename and a sentence of context is enough. Humboldt will figure out the rest.

## After reading

Humboldt moves processed items to `inbox/processed/` and notes them in the session's lab notebook entry. If an item requires action (add to library, open a hypothesis, investigate a claim), Humboldt will do that and note it.

## Future intake paths

- **Telegram:** a bot command will eventually write to this inbox directly
- **Discord:** `#humboldt-inbox` channel (planned) will be monitored and mirrored here
